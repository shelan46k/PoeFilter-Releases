# PoeFilter：流亡黯道物品過濾器中文編輯器

用中文看懂、修改流亡黯道（Path of Exile）3.30 的物品過濾器（`.filter`）。

## 下載

**[按這裡下載最新版 PoeFilter.exe](https://github.com/shelan46k/PoeFilter-Releases/releases/latest/download/PoeFilter.exe)**

所有版本與更新說明：[Releases](https://github.com/shelan46k/PoeFilter-Releases/releases)

- 不需要安裝，下載後雙擊 `PoeFilter.exe` 就能使用。
- 不需要另外安裝 .NET。
- 只支援 Windows 10／11（64 位元）。

## 第一次開啟

如果出現「**Windows 已保護您的電腦**」：

1. 按「**其他資訊**」
2. 按「**仍要執行**」

這是因為程式沒有付費購買數位簽章，不是病毒警告。只有第一次會出現。

## 放在哪裡

建議放在 **桌面**、**下載** 或 **自己建立的資料夾**。

請不要放在 `C:\Program Files`：那裡 Windows 不允許程式修改自己，會**無法自動更新**（程式仍可正常使用，開啟時會提醒你）。

## 主要功能

- **中文顯示**：物品類別、物品基底、條件都用中文顯示，也可以切換回英文。
- **外觀預覽**：直接看到物品在遊戲裡掉落時的樣子，調整顏色、字體、小地圖圖示、光柱與音效。
- **條件編輯**：用中文搜尋挑選物品，不用記英文名稱。
- **物品查詢**：輸入物品名稱，找出它最後會套用哪一條規則。
- **檢查**：找出遊戲會讀錯的寫法，以及 3.30 已經改名或移除的物品。
- **過濾器清單**：新增、複製、重新命名、刪除過濾器（刪除會放進資源回收筒）。
- **自動備份**：每次存檔前自動備份，存錯了可以「從備份還原」。
- **自動更新**：有新版本時會詢問你，按了才更新，不會偷偷更新。

## 使用方式

1. 開啟程式，在左邊「變更資料夾…」選擇遊戲的過濾器資料夾，通常是：
   `文件\My Games\Path of Exile`
2. 在清單點一下要修改的過濾器。
3. 修改後按「儲存」。
4. 回到遊戲：選項 → 遊戲 → 物品過濾器，重新選擇或按旁邊的重新整理。

建議先用「複製」做一份自己的過濾器再修改，原本的檔案就不會被改到。

## 常見問題

**Q：會不會被封號？**
程式只修改電腦上的 `.filter` 文字檔，不會讀取或修改遊戲本身，也不會連線到遊戲伺服器。過濾器是遊戲官方允許玩家自訂的功能。

**Q：存錯了怎麼辦？**
「檔案 → 從備份還原…」可以挑之前的版本載回來。確認沒問題再按儲存。

**Q：設定存在哪裡？**
設定在 `%AppData%\PoeFilter`，備份在 `%LocalAppData%\PoeFilter\backups`。搬動 `PoeFilter.exe` 不會遺失設定。
